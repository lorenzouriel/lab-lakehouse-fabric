## Key Concepts

| Concept | Description |
|---------|-------------|
| **Process group** | One of Initiating / Planning / Execution / Monitoring & Controlling / Closing — not a sequential phase, several run concurrently |
| **Charter** | The document that formally authorizes a project and anchors scope disputes back to one source |
| **Stakeholder matrix** | Influence × interest grid that sets communication cadence and channel per person, revisited periodically |
| **Communication plan** | Who receives what, how often, through which channel — the antidote to ad hoc status updates |
| **Closure document** | Formal record that a project ended on purpose, with what shipped and what was learned |
