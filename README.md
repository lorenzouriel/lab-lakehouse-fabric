# lab-lakehouse-fabric

Medallion lakehouse (Bronze → Silver → Gold) on **Microsoft Fabric**, built from the Fruit Juice dataset generated by [`lab-sources`](../lab-sources).

## Stack

| Layer | Tooling |
|---|---|
| Storage | OneLake |
| Table format | Delta Lake |
| Processing | Fabric Lakehouse, Spark notebooks (PySpark / Spark SQL) |
| Ingestion / orchestration | Data Factory pipelines, Dataflow Gen2 |
| Serving | SQL analytics endpoint, Direct Lake semantic model, Power BI |
| Governance | Workspace roles, OneLake security, Purview |
| CI/CD | Fabric Git integration, `fabric-cicd`, deployment pipelines, GitHub Actions or Azure DevOps |

## Architecture

- **Bronze**: raw files landed in the Lakehouse `Files` area, loaded to Delta tables as-is.
- **Silver**: cleaned, typed, deduplicated tables; data-quality checks in notebooks.
- **Gold**: star schema and KPI marts exposed through a Direct Lake semantic model.
- One workspace per environment (dev / test / prod), or one lakehouse per layer.

## CI/CD plan

- Dev workspace connected to Git (feature branches via branch-out).
- PR: lint and notebook tests; merge triggers `fabric-cicd` to publish to test, then prod, using a service principal.
- Deployment rules parameterise lakehouse and connection IDs per environment.
